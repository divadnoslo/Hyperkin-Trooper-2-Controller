# Hyperkin-Trooper-2-Controller
Python interface for using the Hyperkin Trooper 2 Controller

## Hyperkin Trooper 2 Controller Information

I bought this [controller](https://hyperkin.com/trooper-2-premium-controller-pc-mac-raspberry-pi.html) at a Microcenter in Denver almost three years ago. I have thrown away the packaging, and there does not appear to be any online documentation readily available about how to interface with this thing. 

I figure this would be a fun thing to reverse engineer so I can read the controller inputs and interface those inputs into some servo commands sometime in the future. We will see whaat happens.
